# AZEG - أكاديمية قطاف (نسخة أولية)

واجهة أولية لمنصة تعليمية تحتوي على:
- بوابة دخول بكلمة مرور عامة.
- صفحة كورسات ومكتبة كتب.
- باقات اشتراك وإرسال إثبات الدفع.
- لوحة تحكم مدير لإضافة كورسات وكتب وقبول الطلبات.
- نظام تعليقات، وشهادة تقدير نصية، وبث مباشر.

## التشغيل

افتح ملف `index.html` مباشرة في المتصفح.

## ملاحظة أمنية

كلمات المرور الحالية في الواجهة الأمامية لأغراض العرض التجريبي فقط، ويجب نقلها إلى خادم backend آمن قبل الاستخدام الفعلي.
