# أكاديمية قطاف - نسخة تشغيل محلية

هذه نسخة Frontend تشغيلية محلية مطورة، وتشمل:
- تسجيل دخول بدورين (طالب/مدير).
- إدارة كورسات وكتب من لوحة المدير.
- إرسال إثباتات الدفع وقبولها مع فتح واتساب تلقائيًا.
- ملف طالب (نقاط، حضور، غياب، ورد يومي).
- تعليقات عامة + شهادة تقدير.
- حفظ البيانات في `localStorage` داخل المتصفح.

## طريقة التشغيل
1. افتح `index.html` مباشرة في المتصفح.
2. أو شغل خادم محلي:
   ```bash
   python3 -m http.server 8080
   ```
   ثم افتح:
   `http://localhost:8080`

## بيانات الدخول
- دخول الطالب/الزائر: `waleedzeyada`
- دخول المدير: `waleed`

## ملاحظة أمنية مهمة
هذه نسخة تشغيل محلية وليست إنتاجية. يجب قبل النشر الحقيقي:
- نقل كلمات المرور والصلاحيات إلى Backend آمن.
- ربط قاعدة بيانات حقيقية.
- استخدام نظام دفع API فعلي بدل الروابط اليدوية.
